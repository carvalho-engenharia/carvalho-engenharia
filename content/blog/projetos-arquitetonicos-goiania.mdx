Todo processo de construção começa com um projeto arquitetônico — mas nem todo mundo sabe exatamente o que esse documento deve conter, nem por que ele é a base de tudo o que vem depois: alvará, projeto estrutural, Habite-se. Este guia explica o essencial.

## O que é um projeto arquitetônico?

É o conjunto de desenhos técnicos que representa como será a edificação — a distribuição dos ambientes, dimensões, aberturas, materiais e a relação do imóvel com o terreno e a vizinhança. É a partir do projeto arquitetônico que os demais projetos complementares (estrutural, elétrico, hidrossanitário) são desenvolvidos, e é ele que a Prefeitura analisa para conceder o alvará de construção.

## O que o projeto arquitetônico deve conter

- **Planta de situação**: como a edificação se posiciona no terreno
- **Planta baixa e de locação**: distribuição interna dos ambientes em cada pavimento
- **Plantas dos pavimentos**: detalhamento de cada andar da edificação
- **Cortes**: representação vertical da edificação, mostrando pé-direito e níveis
- **Fachadas**: representação externa da edificação
- **Quadro de áreas**: cálculo detalhado de área construída, área do terreno e índices urbanísticos
- **ART/RRT do responsável técnico**: profissional habilitado que assume a responsabilidade pelo projeto

## Por que o projeto precisa atender ao Plano Diretor

Antes de desenhar qualquer coisa, o projeto precisa respeitar parâmetros definidos pela legislação municipal — recuos obrigatórios, taxa de ocupação, coeficiente de aproveitamento, gabarito de altura, área permeável mínima, entre outros. Um projeto desenhado sem considerar esses limites será recusado na análise da Prefeitura, gerando retrabalho.

## Projeto arquitetônico x projeto de regularização

Quando a construção já existe e você está regularizando, o processo se chama **levantamento arquitetônico**: em vez de desenhar o que será construído, o profissional mede e desenha o que já existe, para depois submeter à Prefeitura como parte do processo de Alvará de Regularização ou Alvará de Aceite.

## O que verificar antes de aprovar um projeto arquitetônico

- Se o projeto está compatível com o uso pretendido do imóvel (residencial, comercial, misto)
- Se os recuos, taxa de ocupação e demais índices urbanísticos estão dentro do permitido para o zoneamento do terreno
- Se existe ART do responsável técnico
- Se o projeto está pronto para receber os projetos complementares sem necessidade de grandes ajustes

## Perguntas frequentes

**Posso alterar o projeto arquitetônico depois de aprovado?**
Sim, mas alterações significativas exigem um processo de modificação de projeto junto à Prefeitura, que também precisa ser aprovado antes da execução da mudança.

**Quanto tempo leva para desenvolver um projeto arquitetônico?**
Varia conforme a complexidade da edificação e o número de revisões necessárias até o cliente aprovar o layout final.

**O projeto arquitetônico já inclui o projeto estrutural?**
Não — são projetos complementares desenvolvidos por profissionais diferentes (arquitetônico e estrutural, entre outros), que precisam estar compatibilizados entre si.
